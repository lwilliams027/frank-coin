# Frankoin ($FRANK)

A joke meme-coin landing page for Frank's 35th birthday. Every "Buy $FRANK" button leads to
`gotcha.html`, which admits there is no coin and links to Frank's PayPal for birthday gifts.

Static site, no build step. Hosted on GitHub Pages.

## Editing

- **Payment links:** the PayPal email and optional Venmo handle are set at the top of the script in `gotcha.html`.
- **Copy:** all text lives in `index.html` and `gotcha.html`.
- **Styles:** `assets/style.css`.
- **Mascot:** `assets/frank.png`. The nav coin logo and the hero both use it.
- **Link preview image:** `assets/og.png` (1200×630), referenced from the `og:image` meta tags.
